## 🚀 Selected Projects

### 🤖 Slack Support Assistant — AI-Assisted Support Workflow

A private prototype designed around a real-world technical support workflow.

The system explores how a support team could manage incoming Slack conversations more efficiently.

**Workflow includes:**

- Customer submits a support request in Slack
- A conversation is automatically created
- An engineer is assigned using round-robin logic
- Engineer availability is considered during assignment
- Customer receives an acknowledgement
- Engineer can review the conversation
- AI-assisted response drafts can be generated
- Engineer can edit, reject, regenerate, or approve a response
- Approved responses can be sent as the assigned engineer
- Conversation and acknowledgement states are tracked

The project was built as an experiment to understand how AI-assisted tooling could support — rather than replace — human technical support workflows.

> **Repository:** Private  
> **Focus:** Support workflow design • Automation • Slack workflows • AI-assisted tooling
